# Folduct 인수 검증표

기준은 `docs/folduct-web-prd-v1.0.md`의 AC01~27이다. 아래 체크는 모두 미실행 상태로 시작한다. 테스트 방법의 힌트는 원래 기준을 축소하지 않는다.

## 기록 규칙

통과한 항목만 체크한다. 각 항목 아래에 실행일, 환경, 방법, 실제 결과, 관련 테스트 파일 또는 기록 경로를 추가한다. 환경상 실행하지 못했으면 ‘미검증’으로 남긴다. 자동화된 모의 검증과 실제 파일·권한 검증은 구분한다.

0단계(2026-10-04)는 기존 코드 점검과 기준 빌드만 수행했다. AC01~27과 추가 시나리오, 사용자 실험은 실행하지 않았으며 아래 체크는 모두 미검증이다.

## 저장과 장면

2026-10-06 보강: 작업 복사본의 자동 테스트에서 중단 요청 중복 방지, 현재 작업·장면 원자 저장, 안전 장면 왕복, 강제 실패 롤백, 개정 충돌을 확인했다. 로컬 브라우저 샘플에서는 중단·재개 요약·장면 전환과 새로고침 후 복원을 확인했다. 아래 AC10~14는 실제 폴더와 브라우저 프로세스 재실행 등 남은 경로가 있어 미검증을 유지한다.

- [ ] AC10 저장 완료 후 브라우저 재실행에서도 마지막 확정 상태가 복원된다. 현재 작업과 장면을 구분해 확인한다. 담당 단계 3과 5.

- [ ] AC12 중단 버튼 연속 클릭으로 장면이 중복 생성되지 않는다. 담당 단계 5.
- [ ] AC13 과거 장면에서 이어가기 전 상태가 안전 장면에 남고 다시 이어갈 수 있다. 담당 단계 5.

## 추가 전체 시나리오

- [ ] 처음 실행 → 실제 폴더 연결 → 카드 3개 → 이유 메모 → 다음 행동 → 중단 → 재실행 → 이어서 시작.
- [ ] 수동 장면 → 현재 작업 변경 → 과거 장면 열람 → 취소 시 현재 작업 유지 → 장면에서 이어가기 → 안전 장면 확인.
- [ ] 명시적 중단 없이 닫기 → 마지막 자동 저장 복원 → 미확정 변경의 한계를 정확히 안내.
- [ ] 백업을 별도 새 저장 공간으로 가져오기 → 폴더 재연결 → 파일·카드·장면 참조 확인.
- [ ] 데모 초기화 또는 프로젝트 메타데이터 삭제가 사용자 원본과 다른 프로젝트를 변경하지 않음.
- [ ] 1024px 패널 전환, 좁은 화면, 200% 확대와 키보드에서 주요 작업 접근 확인.
  - 2026-10-04, Cursor 내장 브라우저. 1400×700에서 책상은 높이 603에 맞춰 965×603(비율 1.6)이고 문서 스크롤은 없었다. 1100px에서는 작업면이 남고 자료 목록은 버튼으로 겹쳐 열렸다. 390×844에서는 책상이 목록으로 열리고 프로젝트는 작업면·자료·메모 탭으로 전환됐다. 카드 좌표는 72와 848 그대로였다. 200% 확대와 키보드 전체 여정은 아직 미검증이다.
