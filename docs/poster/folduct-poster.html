작업 폴더마다 방이 하나 생겨요. 방은 캐릭터 프로도, 파일은 이름이 적힌 종이예요. 색은 파일 형식, 크기는 용량이에요.

받은 파일은 쌓이고,
정리는 늘 다음으로 밀려요.

어느 작업 파일인지 금방 잊혀요. Finder는 언제 치울지 알려 주지 않고, 자동 정리 앱은 지울까 봐 맡기기 어려워요.

Folduct는 지우지 않고, 옮기기만 해요.

새 파일은 작업 중인 방으로, 안 쓴 파일은 정리 상자로. 언제든 되돌릴 수 있어요.
