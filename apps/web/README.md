# Folduct Web

선택한 로컬 폴더를 읽고, 프로젝트 책상과 작업면의 카드·이유 메모를 이 브라우저에 저장하는 웹 앱입니다. 샘플 체험은 `folduct-demo` 저장소를 쓰며 실제 프로젝트 저장소와 분리되어 있습니다.

선택한 카드에서 PNG·JPEG·WebP, 텍스트, 브라우저가 재생하는 영상·음원, PDF를 미리봅니다. HTML·SVG·Markdown은 실행하지 않고 텍스트로 보여 줍니다. 여기서 멈추기 장면은 아직 이후 단계입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저 보안상 사용자가 직접 선택한 폴더만 읽을 수 있습니다. 파일 원본은 서버로 업로드하지 않습니다.
